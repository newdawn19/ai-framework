## 维护约定

- 产品经理创建 `Draft` 本地 DP 时，将其加入“待确认决策”。
- Local Decision Owner 接受后，产品经理将其移动到“当前有效决策”。
- 本地 DP 被新决定取代时，将其移动到“已被取代”，并在新旧本地 DP 正文中记录双向链接。
- Local Decision Owner 拒绝后，将其移动到“已拒绝提案”；拒绝记录不具有执行授权。
- 索引更新与本地 DP 创建或状态变化放在同一次治理提交中。
- 每条摘要保持一至三行，不复制完整决定、验收条件或证据。
- 不记录凭据、生产地址、客户私有数据或运行时资产。
